## Platform Setup: How to Structure Your Channel for Algorithm Wins.

Three platforms, three different games. YouTube rewards consistency and watch time. TikTok rewards novelty and first-3-second hooks. Instagram rewards visual quality and shares. Seedance 2.0 can feed all three — but the output needs to be formatted differently for each.

📋 Prompt — YouTube Short Script Generator

```
Write a YouTube Shorts script for a faceless AI video channel. Niche: [your niche]. Topic: [specific topic].

Format requirements:
— Total length: 45–58 seconds when read at normal pace
— First line: a pattern-interrupt hook that creates a knowledge gap
— No filler phrases: no "In this video", "Hey guys", "Don't forget to subscribe"
— Each sentence is a standalone visual moment (I will generate each as a separate Seedance clip)
— End with an open loop that drives watch time on the next video
— Tone: confident, slightly urgent, no fluff

Output format: numbered list of sentences, each followed by a [VISUAL NOTE] describing what the Seedance clip for that sentence should show.
```

Platform Format Rules

> YouTube Shorts: 9:16 ratio, 45–58 seconds, add chapters even on Shorts. TikTok: 9:16, first 3 seconds must be a visual hook — no black frames. Instagram Reels: 9:16, 15–30 seconds performs best for Explore page reach. Generate separate exports for each platform — never cross-post raw without format adjustment.
